README.md# Weather Dashboard

A real-time Weather Dashboard built using asynchronous JavaScript and RESTful APIs.

## Features

- Search weather by city name
- Real-time weather information
- Fetch API
- Async/Await
- RESTful API
- JSON parsing
- Dynamic DOM manipulation
- Error handling
- Loading state
- Temperature
- Humidity
- Wind speed
- Feels-like temperature
- Cloud cover
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- REST API
- Open-Meteo API

## API Used

Open-Meteo provides the geocoding and weather data used by this application.

## Assignment Requirements

### Fetch API and Async/Await

The application uses `fetch()` with `async/await` to retrieve data from REST APIs.

### Error Handling

Network and HTTP errors are handled using `try/catch` and response status checking.

### JSON Processing

The application processes JSON responses from the API and extracts nested weather properties.

### City Search

Users can enter a city name to retrieve its current weather information.
